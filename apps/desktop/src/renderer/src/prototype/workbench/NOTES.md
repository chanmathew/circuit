# Task Workbench UX Prototype

**Route:** `/prototype/workbench?scenario=questions|research|design|structure|plan|implement|review`

**Exit:** ← Back to app (sidebar) or Exit to app (banner)

## Scenario presets (top bar)

| Button | Phase | Structured panel |
|--------|-------|------------------|
| Questions | Questions review | Human Q&A cards — answer or defer |
| Research | Research review | Confirm / dispute findings |
| Design | Design review | Key decisions + open questions (same A/B/C cards) |
| Structure | Structure review | Approve vertical slices |
| Plan | Plan review | Slice accordion + approve each |
| Implement | Diff review | Slice feedback textarea |
| Review | Final review | Checklist (blocks approve) |

## Iteration UX (all artifact phases)

1. **Markdown** in main panel (source / preview) — scrolls with structured content below
2. **Structured section** inline under the doc (same scroll); phase-specific cards
3. **Request revision** → panel swaps to a single note field; **Submit revision** / **Cancel** in bottom bar
4. **Proceed to …** always visible in bottom bar during review (disabled until structured items complete); muted hint explains why
